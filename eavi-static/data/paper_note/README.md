# paper_note/ —— 论文阅读笔记上传目录

这个目录存放用户上传的论文阅读笔记文件，通过 `/data/paper_note/{filename}` 访问。

## ⚠️ 本目录内容不入版本库

**原因**：原目录里有一个 748 KB 的已发表论文 PDF
（`1768635308827_合成疼痛表情数据：AI驱动临床评估新范式.pdf`），
是团队测试时上传的。本仓库是**公开仓库**，收录他人已发表的论文全文有版权风险。

## 你要做什么

- **测试上传功能**：随便找一个无版权顾虑的文件（自己写的 Markdown、公开授权的 PDF、任意图片）。
- **不要提交**他人的论文全文、书籍扫描件、或任何你不确定授权的材料。
- 生成的文件名统一用 `时间戳_清理后的原文件名` 格式（参考参考实现
  `PaperCodeServiceImpl.uploadCodeFiles` 的做法）。

## 目录会被保留

Git 不跟踪空目录，所以这个 README 也起到占位作用，保证目录结构存在。
后端启动时如果目录不存在，应当自动创建（参考实现里有这个逻辑）。
